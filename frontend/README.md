# EduNexa

A premium full-stack academic performance and study habit analyzer built for Probability & Statistics (MA112). 

## Features
- **Authentication**: JWT-based login/register with SQLite.
- **Dashboard**: KPI metrics and interactive charts.
- **Data Manager**: Edit and manage the synthetic student dataset.
- **Predictor**: Live multiple linear regression predictions for student marks.
- **Statistical Testing**: Integrated T-Tests, Z-Tests, and Bayes' Theorem.
- **PDF Reports**: Export analysis cleanly to PDF.

## How to Run

1. `cd backend`
2. `python -m venv venv`
3. `venv\Scripts\pip install -r requirements.txt`
4. `venv\Scripts\python app.py`
5. Open `http://localhost:8000` in your browser.
